## منطق محاسبات (عدد به عدد)
### 1. جمع فروش کالا
```
3 × 1,000,000 = 3,000,000
```
### 2. تخفیف کمپین
```
3,000,000 × 15٪ = 450,000
مبلغ خالص کالا: 3,000,000 - 450,000 = 2,550,000
```
### 3. مالیات کالا
```
2,550,000 × 10٪ = 255,000
```
### 4. باربری
```
باربری = 100,000
مالیات باربری = 100,000 × 10٪ = 10,000
```
### 5. مبلغ نهایی دریافتی
```
2,550,000 + 255,000 + 100,000 + 10,000 = 2,915,000
```
