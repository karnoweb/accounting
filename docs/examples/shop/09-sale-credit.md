## سناریو
فروش نسیه کالا (بدون پرداخت اولیه).
---
## فرضیات
* تعداد محصولات: 3 عدد
* قیمت هر محصول: 1,000,000 تومان
* تخفیف محصول: ندارد
* تخفیف فاکتور: ندارد
* هزینه باربری: 100,000 تومان (مشمول مالیات)
* نرخ مالیات بر ارزش افزوده: 10٪
* روش پرداخت: نسیه کامل

## منطق محاسبات (عدد به عدد)
### 1. جمع فروش کالا
```
3 × 1,000,000 = 3,000,000
```
### 2. تخفیف
```
ندارد → مبلغ تغییری نمی‌کند
```
### 3. مالیات کالا
```
3,000,000 × 10٪ = 300,000
```
### 4. باربری
```
باربری = 100,000
مالیات باربری = 100,000 × 10٪ = 10,000
```
### 5. مبلغ نهایی
```
3,000,000 + 300,000 + 100,000 + 10,000 = 3,410,000 (به عنوان دریافتنی ثبت می‌شود)
```
