# 03-sale-cash-invoice-discount.md
## سناریو
فروش نقدی کالا با تخفیف روی فاکتور (تخفیف کلی روی جمع فاکتور) اما بدون تخفیف محصول.

> این فایل مثال دامنه است. «تخفیف روی جمع فاکتور» و «نحوه محاسبه مالیات» قرارداد هسته پکیج نیست؛ این سیاست‌ها در اپ مصرف‌کننده تعریف می‌شوند و سپس باید به شکل سند متعادل در هسته ثبت شوند.

---
## فرضیات
* تعداد محصولات: 3 عدد
* قیمت هر محصول: 1,000,000 تومان
* تخفیف محصول: ندارد
* تخفیف فاکتور: 10٪ روی جمع کالا
* هزینه باربری: 100,000 تومان (مشمول مالیات)
* نرخ مالیات بر ارزش افزوده: 10٪
* روش پرداخت: نقدی

## منطق محاسبات (عدد به عدد)
### 1. جمع فروش کالا
```
3 × 1,000,000 = 3,000,000
```
### 2. تخفیف فاکتور
```
3,000,000 × 10٪ = 300,000
مبلغ خالص کالا: 3,000,000 - 300,000 = 2,700,000
```
### 3. مالیات کالا
```
2,700,000 × 10٪ = 270,000
```
### 4. باربری
```
باربری = 100,000
مالیات باربری = 100,000 × 10٪ = 10,000
```
### 5. مبلغ نهایی دریافتی
```
2,700,000 (کالا خالص)
+ 270,000 (مالیات کالا)
+ 100,000 (باربری)
+ 10,000 (مالیات باربری)
= 3,080,000
```

## نکات مرجع
* تخفیف فاکتور روی جمع اعمال می‌شود و درآمد را کاهش می‌دهد
* نحوه محاسبه مالیات در این مثال، سیاست دامنه اپ مصرف‌کننده است و هسته پکیج برای آن guard ندارد
