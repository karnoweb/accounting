# 05-sale-cash-no-tax.md
## سناریو
فروش نقدی کالا بدون مالیات (کالا یا باربری مشمول مالیات نیستند).
---
## فرضیات
* تعداد محصولات: 3 عدد
* قیمت هر محصول: 1,000,000 تومان
* تخفیف محصول: ندارد
* تخفیف فاکتور: ندارد
* هزینه باربری: 100,000 تومان (غیرمشمول مالیات)
* نرخ مالیات بر ارزش افزوده: 0٪ (یا معاف)
* روش پرداخت: نقدی
---

## منطق محاسبات (عدد به عدد)
### 1. جمع فروش کالا
```
3 × 1,000,000 = 3,000,000
```
### 2. تخفیف
```
ندارد → مبلغ تغییری نمی‌کند
```
### 3. مالیات کالا
```
3,000,000 × 0٪ = 0
```
### 4. باربری
```
باربری = 100,000
مالیات باربری = 100,000 × 0٪ = 0
```
### 5. مبلغ نهایی دریافتی
```
3,000,000 (کالا)
+ 0 (مالیات کالا)
+ 100,000 (باربری)
+ 0 (مالیات باربری)
= 3,100,000
```
