# 27-multi-tax-rate.md
## سناریو
فروش با نرخ‌های مختلف مالیات.
---
## فرضیات
* محصول A: 1,000,000 تومان، 10٪ مالیات
* محصول B: 1,000,000 تومان، 5٪ مالیات
* محصول C: 1,000,000 تومان، 15٪ مالیات
* تخفیف: ندارد
* هزینه باربری: 100,000 تومان (10٪)
* روش پرداخت: نقدی

## منطق محاسبات (عدد به عدد)
### 1. جمع فروش کالا
```
3 × 1,000,000 = 3,000,000
```
### 2. تخفیف
```
ندارد
```
### 3. مالیات کالا
```
A: 1,000,000 × 10٪ = 100,000
B: 1,000,000 × 5٪ = 50,000
C: 1,000,000 × 15٪ = 150,000
جمع مالیات کالا: 300,000
```
### 4. باربری
```
باربری = 100,000
مالیات باربری = 100,000 × 10٪ = 10,000
```
### 5. مبلغ نهایی
```
3,000,000 + 300,000 + 100,000 + 10,000 = 3,410,000
```
