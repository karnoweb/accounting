# 02-sale-cash-product-discount.md
## سناریو
فروش نقدی کالا با تخفیف روی محصول (تخفیف روی هر ایتم جداگانه) اما بدون تخفیف فاکتور.
---
## فرضیات
* تعداد محصولات: 3 عدد
* قیمت هر محصول: 1,000,000 تومان
* تخفیف محصول: 10٪ برای هر محصول
* تخفیف فاکتور: ندارد
* هزینه باربری: 100,000 تومان (مشمول مالیات)
* نرخ مالیات بر ارزش افزوده: 10٪
* روش پرداخت: نقدی
---

## منطق محاسبات (عدد به عدد)
### 1. جمع فروش کالا قبل از تخفیف
```
3 × 1,000,000 = 3,000,000
```
### 2. تخفیف محصول
```
هر محصول: 1,000,000 × 10٪ = 100,000
جمع تخفیف: 3 × 100,000 = 300,000
مبلغ خالص کالا: 3,000,000 - 300,000 = 2,700,000
```
### 3. مالیات کالا
```
2,700,000 × 10٪ = 270,000
```
### 4. باربری
```
باربری = 100,000
مالیات باربری = 100,000 × 10٪ = 10,000
```
### 5. مبلغ نهایی دریافتی
```
2,700,000 (کالا خالص)
+ 270,000 (مالیات کالا)
+ 100,000 (باربری)
+ 10,000 (مالیات باربری)
= 3,080,000
```
