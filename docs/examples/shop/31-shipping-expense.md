## منطق محاسبات (عدد به عدد)
### 1. جمع فروش کالا
```
3 × 1,000,000 = 3,000,000
```
### 2. مالیات کالا
```
3,000,000 × 10٪ = 300,000
```
### 3. باربری هزینه
```
150,000 (جداگانه ثبت)
```
### 4. مبلغ نهایی دریافتی
```
3,000,000 + 300,000 = 3,300,000
```
