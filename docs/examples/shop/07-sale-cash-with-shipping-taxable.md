# 07-sale-cash-with-shipping-taxable.md
> این فایل یک **مثال دامنه‌محور** است. این‌که «باربری مشمول مالیات است» یا «مالیات جداگانه محاسبه می‌شود» به منطق اپ مصرف‌کننده و نگاشت حساب‌های پروژه شما وابسته است.

## سناریو
فروش نقدی با باربری مشمول مالیات.
---
## فرضیات
* تعداد محصولات: 3 عدد
* قیمت هر محصول: 1,000,000 تومان
* تخفیف محصول: ندارد
* تخفیف فاکتور: ندارد
* هزینه باربری: 100,000 تومان (مشمول مالیات)
* نرخ مالیات بر ارزش افزوده: 10٪
* روش پرداخت: نقدی

## منطق محاسبات (عدد به عدد)
### 1. جمع فروش کالا
```
3 × 1,000,000 = 3,000,000
```
### 2. تخفیف
```
ندارد → مبلغ تغییری نمی‌کند
```
### 3. مالیات کالا
```
3,000,000 × 10٪ = 300,000
```
### 4. باربری
```
باربری = 100,000
مالیات باربری = 100,000 × 10٪ = 10,000
```
### 5. مبلغ نهایی دریافتی
```
3,000,000 (کالا)
+ 300,000 (مالیات کالا)
+ 100,000 (باربری)
+ 10,000 (مالیات باربری)
= 3,410,000
```
