# 29-tax-return.md
> این فایل یک مثال دامنه‌محور برای تسویه مانده حساب مالیات است. هسته پکیج فرآیند اظهارنامه، محاسبه بدهی قانونی یا پرداخت به دولت را مدیریت نمی‌کند؛ فقط ثبت دوبلِ متعادل را می‌پذیرد.
## سناریو
تسویه مانده حساب مالیات از طریق پرداخت بانکی، بر مبنای مانده‌ای که اپلیکیشن مصرف‌کننده قبلاً در حساب‌های خود شناسایی کرده است.

* پرداخت از بانک به مرجع بیرونی

## نکات مرجع
* این سند فقط مانده یک حساب بدهی را صفر یا کمتر می‌کند و محاسبه مالیات دوره را انجام نمی‌دهد.
* عنوان حساب `مالیات پرداختنی` نمونه است و باید با ساختار chart of accounts پروژه شما تطبیق داده شود.
* اگر پروژه شما برای مالیات فروش، عوارض، یا تسویه‌های بین‌دوره‌ای حساب‌های جداگانه دارد، تفکیک آن‌ها باید در اپ مصرف‌کننده انجام شود.
