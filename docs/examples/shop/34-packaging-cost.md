# 34-packaging-cost.md
> این فایل یک مثال دامنه‌محور است. هسته پکیج هیچ ماژول بسته‌بندی یا policy آماده‌ای برای اخذ/ثبت هزینه بسته‌بندی ندارد؛ فقط فرض می‌کنیم اپلیکیشن مصرف‌کننده این مبلغ را در فاکتور محاسبه و به حساب‌های مناسب نگاشت کرده است.
## سناریو
افزودن مبلغ بسته‌بندی به فاکتور فروش، با این فرض که فروشگاه این مبلغ را از مشتری دریافت می‌کند و به‌صورت جداگانه در حساب‌ها نشان می‌دهد.
---
## فرضیات
* مبلغ بسته‌بندی: 50,000 تومان (در این مثال به‌عنوان درآمد/دریافت جداگانه)
* بقیه مشابه 01
---

## منطق محاسبات (عدد به عدد)
### 1. جمع فروش کالا
```
3,000,000
```
### 2. باربری
```
100,000 + 10,000 مالیات
```
### 3. بسته‌بندی
```
50,000 + 5,000 مالیات = 55,000
```
### 4. مبلغ نهایی
```
3,300,000 + 110,000 + 55,000 = 3,465,000
```

## نکات مرجع
* این مثال فقط یکی از تفسیرهای دامنه‌ای را نشان می‌دهد: دریافت مبلغ بسته‌بندی از مشتری.
* هسته پکیج تصمیم نمی‌گیرد بسته‌بندی «هزینه» است، «درآمد» است، یا باید در بهای تمام‌شده جذب شود.
* اگر بسته‌بندی در پروژه شما مشمول مالیات نباشد یا حساب جداگانه داشته باشد، باید همان سیاست در لایه اپلیکیشن اعمال شود.
