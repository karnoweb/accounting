# 04-sale-cash-product-and-invoice-discount.md
## سناریو
فروش نقدی کالا با تخفیف روی محصول و همچنین تخفیف روی فاکتور.

> این فایل مثال دامنه است. این‌که «تخفیف محصول» و «تخفیف فاکتور» چگونه روی اعداد اثر می‌گذارند، قرارداد هسته پکیج نیست؛ سیاست‌های محاسباتی و نگاشت حساب‌ها باید در اپ مصرف‌کننده مشخص شود.

---
## فرضیات
* تعداد محصولات: 3 عدد
* قیمت هر محصول: 1,000,000 تومان
* تخفیف محصول: 10٪ برای هر محصول
* تخفیف فاکتور: 5٪ روی جمع پس از تخفیف محصول
* هزینه باربری: 100,000 تومان (مشمول مالیات)
* نرخ مالیات بر ارزش افزوده: 10٪
* روش پرداخت: نقدی

## منطق محاسبات (عدد به عدد)
### 1. جمع فروش کالا قبل از تخفیف
```
3 × 1,000,000 = 3,000,000
```
### 2. تخفیف محصول
```
هر محصول: 1,000,000 × 10٪ = 100,000
جمع تخفیف محصول: 3 × 100,000 = 300,000
مبلغ پس از تخفیف محصول: 3,000,000 - 300,000 = 2,700,000
```
### 3. تخفیف فاکتور
```
2,700,000 × 5٪ = 135,000
مبلغ خالص کالا: 2,700,000 - 135,000 = 2,565,000
```
### 4. مالیات کالا
```
2,565,000 × 10٪ = 256,500
```
### 5. باربری
```
باربری = 100,000
مالیات باربری = 100,000 × 10٪ = 10,000
```
### 6. مبلغ نهایی دریافتی
```
2,565,000 (کالا خالص)
+ 256,500 (مالیات کالا)
+ 100,000 (باربری)
+ 10,000 (مالیات باربری)
= 2,931,500
```
