## منطق محاسبات (عدد به عدد)

### 1. جمع فروش کالا

```
3 × 1,000,000 = 3,000,000
```

### 2. مالیات کالا

```
3,000,000 × 10٪ = 300,000
```

### 3. باربری

```
باربری = 100,000
مالیات باربری = 100,000 × 10٪ = 10,000
```

### 4. هزینه خدمات

```
80,000 + (80,000 × 10٪) = 80,000 + 8,000 = 88,000
```

### 5. مبلغ نهایی دریافتی

```
3,000,000 (کالا)
+ 300,000 (مالیات کالا)
+ 100,000 (باربری)
+ 10,000 (مالیات باربری)
+ 80,000 (خدمات)
+ 8,000 (مالیات خدمات)
= 3,498,000
```
