# 08-sale-cash-with-shipping-non-taxable.md
## سناریو
فروش نقدی با باربری غیرمشمول مالیات.

> این فایل یک مثال دامنه‌محور است و نحوه رفتار مالیات/تفکیک ردیف‌های مالیاتی فقط وقتی قابل تفسیر است که سیاست مالیاتی اپ و نگاشت حساب‌های پروژه شما مشخص باشد.
---
## فرضیات
* تعداد محصولات: 3 عدد
* قیمت هر محصول: 1,000,000 تومان
* تخفیف محصول: ندارد
* تخفیف فاکتور: ندارد
* هزینه باربری: 100,000 تومان (غیرمشمول مالیات)
* نرخ مالیات بر ارزش افزوده: 10٪ برای کالا، 0٪ برای باربری
* روش پرداخت: نقدی
---

## منطق محاسبات (عدد به عدد)
### 1. جمع فروش کالا
```
3 × 1,000,000 = 3,000,000
```
### 2. تخفیف
```
ندارد → مبلغ تغییری نمی‌کند
```
### 3. مالیات کالا
```
3,000,000 × 10٪ = 300,000
```
### 4. باربری
```
باربری = 100,000
مالیات باربری = 100,000 × 0٪ = 0
```
### 5. مبلغ نهایی دریافتی
```
3,000,000 (کالا)
+ 300,000 (مالیات کالا)
+ 100,000 (باربری)
+ 0 (مالیات باربری)
= 3,400,000
```

## نکات مرجع
* «باربری بدون مالیات» یا «باربری به عنوان درآمد بدون مالیات» یک فرض دامنه اپ است و به سیاست مالیاتی و نگاشت حساب‌های `Account` شما بستگی دارد.
* این‌که مالیات فقط روی کالا اعمال شده یا شامل ردیف‌های دیگر هم هست، قرارداد اپ مصرف‌کننده است، نه guard هسته پکیج.
