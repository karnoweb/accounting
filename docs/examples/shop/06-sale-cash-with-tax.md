# 06-sale-cash-with-tax.md
## سناریو
فروش نقدی کالا با مالیات (مشابه سناریو پایه اما تاکید روی وجود مالیات).

> این فایل مثال دامنه است. وجود/عدم وجود مالیات و نگاشت آن به حساب‌ها، تصمیم اپ مصرف‌کننده است؛ هسته فقط «سند متعادل» را می‌پذیرد.
---
## فرضیات
* تعداد محصولات: 3 عدد
* قیمت هر محصول: 1,000,000 تومان
* تخفیف محصول: ندارد
* تخفیف فاکتور: ندارد
* هزینه باربری: 100,000 تومان (مشمول مالیات)
* نرخ مالیات بر ارزش افزوده: 10٪
* روش پرداخت: نقدی

## منطق محاسبات (عدد به عدد)
### 1. جمع فروش کالا
```
3 × 1,000,000 = 3,000,000
```
### 2. تخفیف
```
ندارد → مبلغ تغییری نمی‌کند
```
### 3. مالیات کالا
```
3,000,000 × 10٪ = 300,000
```
### 4. باربری
```
باربری = 100,000
مالیات باربری = 100,000 × 10٪ = 10,000
```
### 5. مبلغ نهایی دریافتی
```
3,000,000 (کالا)
+ 300,000 (مالیات کالا)
+ 100,000 (باربری)
+ 10,000 (مالیات باربری)
= 3,410,000
```

## نکات مرجع
* این سناریو مشابه 01 است با تمرکز روی مالیات
* نحوه ثبت مالیات در این مثال به عنوان یک حساب «Tax Payable» نشان داده شده است؛ اما تصمیم دقیق درباره سمت (debit/credit) و این‌که مالیات را در اپ شما بدهی، کسر از درآمد یا حساب دیگری فرض کنید، فقط با نگاشت chart of accounts و منطق اپ تعیین می‌شود.
