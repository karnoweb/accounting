# 17-sale-credit-note.md
## سناریو
صدور یادداشت اعتباری برای فروش (کاهش دریافتنی).
---
## فرضیات
* مبلغ اولیه فروش: 3,410,000 تومان
* یادداشت اعتباری: 500,000 تومان (برای تخفیف یا اصلاح)
---
## جدول فاکتور فروش
این سناریو فاکتور نیست، یادداشت اعتباری است.
---
## منطق محاسبات (عدد به عدد)

```
3,410,000
```
### 2. یادداشت اعتباری

```

```
